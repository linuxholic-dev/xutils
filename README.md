xutils
============
A tiny Unix-inspired utilities collection written in C 
and C++.

Features(0.1)

- ls
- pwd
- mkdir
- echo
- mv
- touch
- cat
- clear
- rm (work in progress)

Build
============

./build.sh

The binaries will be generated in the "bin/" directory,just run
build.sh so it auto gene bin/

Project Structure

xutils/
├── bin/(build.sh will create)
├── src/
├── build.sh
├── README.md
└── LICENSE

Requirements

- gcc
- g++
- you can use clang as well!
